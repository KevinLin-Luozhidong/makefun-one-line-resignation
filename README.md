# make.fun — The Funniest One-Line Resignation Letter

Bounty: https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947
Prize: $10 split over the top 3 entries ($5 / $3 / $2).

## Entry

`main.py` — Python, standard library only. It writes the one-line
resignation letter of a rate limit, at most 140 characters, to
`/output/entry.txt`. A judge model playing a tired engineering manager
reads the letters two at a time and picks the funnier one.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.txt
python3 main.py                          # writes /output/entry.txt
```
